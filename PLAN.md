# Implementation Plan

Goal: turn a folder of transparent PNG/SVG images into print-ready sticker
sheets with hand-cutting guide outlines, first as a Python CLI, later as a
compiled GUI app.

Each phase ends with something usable. Get the user's sign-off on a phase's
scope before starting it.

**Status:** phases 0–4 are built (the user approved building through phase 4
in one go). What's left before the GUI is real-world validation: the user's
own images and a real print (phase 1, open items). GUI (phases 5–6) is
backlog for later.

---

## Phase 0: Prototype ✅

Single script proving the core idea: PNG/SVG in, fixed grid, alpha → contour →
offset → smooth outline, multi-page 300 DPI output.

## Phase 1: Validate with real prints

Before building more, confirm the core is right on paper.

- [x] Test run on a real icon set: pixelarticons, 3×5 A4. The user approved
      the look.
- [x] Fix staircase scallops on diagonal edges. Corridor smoothing (see
      AGENTS.md "How the outline is made"): diagonals are straight, rows of
      legs straighten out, deep notches (crescent moon) survive. `--smooth`
      default raised 2 → 3 mm.
- [x] Grid guide lines (boxes), on by default: dashed, light blue, through
      the middle of the gaps and around the outside; `--grid-lines
      dashed|corners|none`; warning when `--gap` < 2 mm.
- [x] Usage examples in `-h` / `--help` (3 runnable commands, all verified).
- [x] `--calibrate`: cm and inch rulers, 50 mm and 2 in squares, dashed
      frame at the page margin to spot printer clipping.
- [x] Problem images as fixtures: `tests/fixtures/problems/` (generated by
      `tests/fixtures/make_fixtures.py`).
- [ ] Run on the user's real sticker images
- [ ] Print the calibration page and a test sheet at 100% and measure:
      paper size, margins, offset
- [ ] Tune defaults for the user's printer: offset, line width/color,
      smoothing, margin. With 6 mm margin and 4 mm gap the outer guide line
      sits 4 mm from the paper edge; check it prints.

**Exit:** a real printed sheet the user is happy cutting.

## Phase 2: Restructure into a package ✅

- [x] `stickerkanmi/` package: `units`, `config`, `io`, `outline`, `layout`,
      `render`, `cli`; run from a checkout with `python -m stickerkanmi`
- [x] Settings as a `SheetConfig` dataclass (all lengths in mm)
- [x] `pyproject.toml` with a `stickerkanmi` console entry point
- [x] pytest: units, layout math, outline geometry (one polygon, clearance,
      offset distance, merged pieces, holes, specks), rendering, I/O
- [x] Golden-image test (`tests/golden/problems_a4_100dpi.png`)

## Phase 3: Layout features ✅

- [x] `--grid auto --size 50mm`: as many cells of that size as fit, centred
- [x] `--size` with a fixed `--grid`: fixed cells, error if they don't fit
- [x] `--sizing fill|uniform`. The plan's third mode ("fixed physical size")
      became `--size` (cell = finished sticker) plus a per-file `size`.
- [x] Inches: lengths accept `mm`/`cm`/`in`; `--units mm|in` for plain
      numbers and messages
- [x] Auto-rotate 90° when the art prints ≥3% larger (`--rotate auto|never`,
      default auto)
- [x] `--copies N` and `--fill-page`
- [x] Per-file overrides in `<folder>/stickers.toml`: copies, size, rotate,
      skip
- [ ] Packed layout (non-grid nesting): stretch goal, not built. Only if the
      grid wastes too much on the user's real sheets.

## Phase 4: Outline & output options ✅

- [x] JPG output as the default (quality 95, no chroma subsampling, DPI and
      sRGB profile embedded); `--format png` or a `.png` `--out` for PNG
- [x] Line styles: `--line-style solid|dashed|dotted` (solid stays default)
- [x] Border fill inside the outline: `--fill-color`
- [x] Sticker-look mock-up: `--preview` writes extra `_preview` pages
- [x] Semi-transparent edges: glows and 40%-alpha areas are enclosed; specks
      under 0.6 mm are ignored so noise can't drag the outline out
- [x] Inner cut lines for large holes: `--holes`, `--hole-min` (default 12 mm)
- [x] Performance: A4 3×5 takes ~2 s at 300 DPI and ~6.5 s / ~1 GB at
      600 DPI. Huge sources are downscaled on load; outlines are traced on a
      mask of ≤1000 px.
- [x] Colour: embedded ICC profiles (RGB/CMYK/gray) converted to sRGB on
      load; output tagged sRGB

### Findings / follow-ups

- [ ] Small rasters print an "upscaled, may print soft" note per file. That's
      correct, but noisy for a whole folder of small PNGs; maybe summarise.
- [ ] Radial art made of separate pieces (sun rays) gets a gently wavy
      outline. Fine to cut, but could be rounder.
- [ ] Confirm with the user: auto-rotate on by default (it turned the
      pixelarticons human and zap sideways in 3×5 cells).

## Decisions

- **Sizing:** both modes are available (`--sizing fill|uniform`).
- **Units:** inches as well as millimetres.
- **Cut outline:** stays solid; dashed isn't easier to cut along.
- **SVGs:** rasterizing at print resolution is fine.
- **Output:** raster, not PDF. JPG is the default, PNG optional.
- **GUI:** backlog. Focus is getting the CLI working as intended.
